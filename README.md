**ARCADE** — Allelic Recoding via gram-sChmidt for Dominance Effects

C++ tools for encoding biallelic variants for non-additive genetic association analysis. Integrates with [REGENIE](https://github.com/rgcgithub/regenie) and [SAIGE](https://github.com/saigegit/SAIGE).

```bash
docker pull fhlassen/arcade:latest
```

**Documentation**: [frhl.github.io/call_chets](https://frhl.github.io/call_chets/)

## Citation

> Lassen, F.H. et al. (2025). *Genome-wide analysis of non-additive genetic effects*. (in preparation)
